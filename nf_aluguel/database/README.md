# Banco do Sistema de Aluguel

Os diretórios `migrations/` e `seeds/` estão reservados para uma fase futura.

Nesta etapa:

- não existem migrations;
- não existem seeds;
- nenhuma tabela foi criada;
- nenhum SQL foi executado;
- o banco atual do NF Blog não foi alterado.

Antes de adicionar arquivos executáveis, revise [`../docs/DATABASE.md`](../docs/DATABASE.md), defina os nomes finais das entidades e valide os conflitos com as tabelas existentes no banco compartilhado.

Migrations futuras deverão ser pequenas, ordenadas, revisáveis e nunca conter credenciais ou dados reais de clientes. Seeds deverão usar somente dados fictícios e não poderão ser executados automaticamente em produção.
